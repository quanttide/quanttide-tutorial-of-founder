兵棋推演入门教程
兵棋推演的本质是”想定 + 棋子 + 规则 + 裁决“的对抗建模系统——它不是策略游戏，而是一套用棋盘还原战场约束、用骰子模拟随机性、用复盘暴露决策盲区的训练工具。掌握”想定—机动—射击—裁决—复盘“五步循环，你就能从零开推第一局。
一、概念与源流：为什么会有兵棋
兵棋诞生的目的不是娱乐，而是把战争经验”翻译“成可重复训练的规则系统。
• 1812–1824年，普鲁士Kriegsspiel——Baron von Reisswitz父子将象棋式战争游戏改造为使用1:8000地图、专用骰子、独立裁判（Umpire）和双盲信息的军官训练工具，1824年获普鲁士总参正式列装，奠定了现代兵棋”棋子+地图+裁判+裁决“的范式。
• 自由兵棋（Free Kriegsspiel）——Verdy du Vernois等人简化繁复表格，让裁判依据军事判断直接裁决，确立了”规则服务想定，而非想定迁就规则“的思想。
• 二战后专业化——运筹学、Lanchester方程、蒙特卡罗方法进入兵棋，催生军事运筹学与作战模拟学；美国海军战争学院、兰德公司大量使用。
• 今天——兵棋已扩展到计算机化、人机混合、AI对抗（如国内”灵弈“”智空“等系统），但其内核仍然是”想定—决策—裁决—反馈“。
理解这一源流能帮你避免一个最常见的误区：兵棋的核心价值是暴露决策问题，而非分出胜负。
二、兵棋六大要素：上手前必须认识的部件
任何一套兵棋（手工或数字）都由以下六部分构成，缺一不可。
要素	作用	新手关注点
地图（棋盘）	量化战场：六角格网、地形、道路、水系、高程	每格代表多少米/公里（战术级常为50m/格）
棋子（算子）	代表作战单位（坦克、步兵、炮兵营）	棋子上的数字 = 战斗力 / 防御力 / 机动点数
规则手册	规定”能干什么、怎么干、干到什么程度“	先看回合流程图，再读细节条款
裁决表（CRT）	用力量对比+骰子查表定结果	兵棋的”发动机“，决定一切对抗结果
骰子	引入不确定性，模拟”战争迷雾“与战场偶然性	D6（六面）或D10（十面）
想定	兵力配置、作战背景、胜负条件、回合数	没有想定的兵棋只是空架子
算子上的数字怎么看：以一个步兵营棋子”4-3-5“为例，含义是——攻击力4 / 防御力3 / 机动点数5。机动点数决定该单位一回合内能穿越几个六角格，穿越不同地形消耗不同点数（平原1点、丛林2点、跨河+2点）。
三、推演流程：一回合内会发生什么
下面以经典的”Igo-Ugo“（你走完我走）回合结构为例，这是几乎所有入门兵棋的默认框架。
┌─────────────── 回合 N ───────────────┐
│ ① 先手判定（首次掷骰，此后按规则轮替） │
│ ② 先手方：机动阶段 → 射击阶段 → 突击阶段 │
│ ③ 后手方：同上                        │
│ ④ 结算阶段：补给检查 / 目标占领判定    │
│ ⑤ 进入回合 N+1                        │
└──────────────────────────────────────┘
第1步：想定简报
裁判或想定书向红蓝双方交代：作战背景、可用兵力、部署区域、胜负条件、回合数。这一步在Kriegsspiel传统中是”背对背“的——双方只知道自己兵力，对手情况由裁判掌握。
第2步：机动阶段
• 每个单位按机动点数在六角格上移动，进入不同地形消耗不同点数。
• 移动完成后放置”机动“注记棋子，表示该单位本回合已行动，不能再动。
• 关键约束：单位必须有补给线（通往己方补给源的通路），否则战斗力减半或不能行动。
第3步：射击/交战阶段
• 攻击方宣告”哪个单位 → 打哪个目标“，通常需满足”相邻“或”射程内“且通视（两格中心连线不被地形遮挡）。
• 计算力量比：攻击力 ÷ 防御力 = Odds（如 8 ÷ 4 = 2:1）。
• 投掷骰子，按 Odds 列在CRT上查行，按骰值查列，得到结果（如”退2“= 后退两格、”歼“= 移除棋子、”压“= 压制）。
第4步：裁决示例
红方坦克连（攻击力8）射击相邻的蓝方步兵排（防御力4）。
Odds = 8 : 4 = 2 : 1。
掷D6得 5，查CRT 2:1行、骰值5列 → 结果”Defender Retreat 2“（防御方退2格）。
蓝方步兵撤出该六角格，红方占领并夺取该要地得分。
第5步：结算与复盘
回合结束后判定目标占领、统计得分；一局结束后必须复盘——回放每个关键决策点，回答”当时为什么这样选？换成另一种方案结果会如何？“。复盘是兵棋推演区别于普通桌游的核心环节。
四、第一次开推：一个完整的新手想定
以下是一个30分钟内能推完的微型想定，按Sabin”简化兵棋“的设计思路编写，专为第一次上手的人准备。
《桥头突击》想定卡
项目	内容
地图	8×6六角格。中央第4列有一条南北向河流，仅在（4,3）有一座桥梁；河西岸为红方，东岸为蓝方。两处”要地“H1（蓝方后方，5分）和H2（桥头东侧，3分）。
回合数	5回合
红方兵力	1个坦克连（6-4-6，可跨河）、1个摩步连（5-3-5）、1个炮兵营（射程3格，攻击力4，不需相邻）
蓝方兵力	1个装甲排（5-5-5）、2个步兵排（3-4-4）
胜利条件	5回合结束累计得分高者胜；占领要地按分值计分，击毁敌方1个单位+1分；回合中要地被击退方占据则得分归零
先后手	开局掷D6，单数蓝方先，双数红方先；此后每回合轮替
裁决表（CRT·D6版）
力量比	骰1	骰2	骰3	骰4	骰5	骰6
1:2	AE*	AE	AE	AE	AR	AR
1:1	AE	AR	AR	AR	DR	DR
2:1	AR	DR	DR	DR	DE	DE
3:1	DR	DR	DE	DE	DE	DE
*AE = 攻方退1 / AR = 攻方后撤 / DR = 防方退1 / DE = 防方被歼灭
地形修正
地形	机动消耗	防御修正
平原/道路	1	无
丛林/居民地	2	防御+1
跨河（非桥）	禁止	—
跨桥	+1	无
山丘	2	防御+1
推演步骤
1. 部署：按想定卡放置棋子，红方在西岸，蓝方在东岸，H1、H2由蓝方占领。
2. 第1回合：掷骰定先手。先手方执行”机动→射击→突击“三阶段；后手方同。机动时把步兵向桥附近靠拢，炮兵营在远距离用4点攻击力打蓝方装甲排（Odds=4:5≈1:1）。
3. 第2–4回合：红方应尝试强渡桥头（机动+1消耗），集火打H2；蓝方则利用防御+1地形迟滞，等待反冲击窗口。
4. 第5回合：判定要地归属，结算得分，宣布胜负。
5. 复盘：用5分钟回答三个问题——渡桥时机是否最佳？炮兵是否打对了目标？哪个骰子结果真正改变了局势？
实操建议
• 第一局找一位朋友对推、一位朋友当裁判；裁判负责查CRT、记分、解释规则争议，比”各自查表“顺畅十倍。
• 没有实体棋子时，可用VASSAL（免费，自带大量模块）或Tabletop Simulator搭建虚拟棋盘。
• 第一局胜负不重要，记录每一次”我本可以…“的瞬间——这才是兵棋真正在训练的能力。
五、从玩家到设计者：下一步学什么
推过2–3局后，你可以按下面顺序深化：
① 补齐理论
• Peter Perla, *The Art of Wargaming*——兵棋概论”圣经“，覆盖历史、设计、专业应用。
• Philip Sabin, *Simulating War*——教你怎么用简化兵棋做战争研究，附多个可立即复制的设计。
• UK MoD, *Defence Wargaming Handbook*——免费PDF，术语最权威。
• 《兵棋与兵棋推演》《计算机兵棋推演技术》——国内系统教材，覆盖Lanchester方程与规则转化。
② 研读真实规则
对照一盒商业兵棋（如《指挥：现代现代行动》）或公开的陆军战术兵棋规则，逐条理解”机动注记“”压制“”通视“”补给“等机制为何这样设计。
③ 设计自己的想定
用上面的《桥头突击》模板改造：换地图（城市战？海战？）、换部队、换胜利条件——每一次改动都会暴露你对战场逻辑的新理解。
④ 进入社群与赛事
• 中国指挥与控制学会（CICC）全国兵棋推演大赛——每年5月启动，设人人对抗、人机混合、手工兵棋多个赛道，省赛/全国总决赛公开报名。
• PAXsims、Connections UK论文集——国际学术视野。
• 期刊——Journal of Defense Modeling and Simulation、Military Operations Research。
六、新手避坑清单
• 把兵棋当策略游戏死磕输赢 → 兵棋的产出是”复盘报告“，不是”胜率“。
• 一开始就啃大部头理论 → 先推一局简易棋再读书，效率高得多。
• 混淆”兵棋“与”计算机仿真“ → 兵棋的核心是人做决策，计算机只是裁决器或加速器。
• 用生活常识替代作战逻辑 → 每条规则都问一句”它模拟了什么现实约束“（地形修正？通信？后勤？）。
• 跳过复盘 → 没有复盘的兵棋只是桌游；复盘时重点回答”哪个假设被推翻了“。
• 想加入来路不明的”内部群“获取”内部数据“ → 仅参与大赛官网、学会、高校军事社团等公开渠道，推演内容限于公开规则与战史。
按这套流程走完第一局，你已经跨过了”知道兵棋是什么“和”会推兵棋“之间的那道门槛——剩下的，就是不断地”想定—对抗—复盘“循环了。
