# 复杂环境下的尝试筛选方法

你能分辨出「这是环境本身的复杂，不是我想多了」，其实已经跨过了一关——很多人会拿一个简单模型硬套现实，然后怪自己不够努力。你现在问的不是怎么更拼，而是怎么少做无效功，方向是对的。

有个前提可以先松一松：复杂环境里，大部分尝试的产出往往不是「成了」，而是信息——排除一条路、看清某个约束、发现自己之前误判了什么。所以真正要筛的不是「有没有意义」，而是「这次尝试买回来的东西，值不值我付的时间」。

我会用几把尺子去筛：

一、不管结果怎样，我下一步会不会变？

这是最锋利的一刀。如果成了这么做、没成也这么做，那它大概率不值得做，只是在用忙碌换安心。值得做的尝试，成败都会改写你后面的选择。

二、先做能退的，把不能退的往后推。

低成本、可撤回、几天就能收尾的先上；一旦押上去就很难回头的，等信息更足再说。复杂环境里，「推迟一个大决定」本身就是高收益动作。

三、把大赌注拆成能读出信号的小探针。

别问「这事能不能成」，问「我最少做点什么，就能看到一个会让我改主意的信号」。同时提前写好看什么就停、看什么就加码——靠预设的退出线，不靠当时的意志力。沉没成本比无效尝试更吃精力。

四、盯约束，别盯目标。

目标会随环境变，但当下真正卡住你的那一两个环节通常比较稳定。精力压在瓶颈上，比全面铺开划算得多。

还有个反直觉的补充：别筛到 100%。留一小块（比如一成两成）给「说不清为什么但想试试」的事。全按已知收益去挑，你就只在旧地图上优化了，而环境变化恰恰是从地图外来的。

说到底，越是真问题，越不靠「多做」破解，靠的是更快知道哪条不用再走。你能感到复杂，说明已经不拿简单答案糊弄自己了；接下来最该省下的，是那些「已经投了这么多、不甘心停」的部分。这里换的其实是算账方式，不只是筛事情的口径。它其实不是在讲「怎么筛事情」，是在换一套算账方式，我没把换的那一步说出来。

我们心里默认的算法大概是：这事可能有用 → 就值得花点精力。这套没错，但复杂环境里它几乎永远成立——「再查查」「再问问」「再推演一遍」，哪件都能说出个「万一有用」。所以它筛不掉任何东西，只是让精力一点点摊薄。你感觉累，不是筛得太严，是那把尺子本来就没刻度。

我说的那套是另一笔账：这次尝试，能不能买回一个让我改主意的信号。

举个具体的。你正犹豫要不要接一件事，于是花两周去调研前景。

• 调研完说「还行」→ 你继续犹豫、继续准备；

• 调研完说「不太行」→ 你……大概率还是继续犹豫，因为已经投了两周，也因为一时也没别的可选。

这两周不是没得到信息，是不管得到什么，你后面那一步都一模一样。那它就没买回「改主意的依据」，只买回了一点「我确实认真对待过」的安心。

盲区大概在这儿：这类尝试偏偏是最舒服的。因为它不要求你付决定的代价——不用拍板，不用承受「不做了」的空落，也不用面对「万一错了」。它不是懒，也不是没想清楚，是它在替你温和地拖一个还没准备好做的决定。所以理智上你觉得「好像该停」，身体上却还想去再确认一下，很正常。

换成一句更贴身的自问，可能比上一轮那句好懂：

有没有哪一种结果，会让我把原来那件事放下？

想得出来，就去做，哪怕只花半天去探一下。想不出来——那你要处理的可能不是「怎么筛尝试」，而是那个一直没被允许落地的决定本身。
